Where the dates come from

Every event's dates come from arknights.wiki.gg, which tracks two dates per event:

  • CN date - when the event ran (or is running) on the CN server.
  • Global date - the same, for the Global/EN server.

An event is marked confirmed as soon as the wiki has a Global date for it, whether that came from an official Gryphline announcement or from something datamined out of the client ahead of one. Either source counts the same here.

How estimates are calculated

An unconfirmed event doesn't just get its own CN date plus a flat average lag. The real CN→Global lag varies enough between events that a flat number tends to leave a gap (or overlap) right where a confirmed date meets an estimated one. Instead:

  1. Events are sorted by CN date.
  2. Each unconfirmed event's Global date = the nearest earlier event's Global date + the CN-side gap between the two.
  3. That "nearest earlier event" can be a confirmed date, or an earlier estimate in the same chain.
  4. Every time a date actually gets confirmed, the chain resets from there.

In short: each estimate carries forward whatever lag was most recently observed, instead of a dataset-wide average.

The CN→Global lag

  • Current lag - the gap between the most recent confirmed event's CN and Global dates. This is what every estimate on the page is using right now.
  • Historical lag - the median lag across every event with both dates known. Only used to bootstrap the very first estimate, before any confirmed CN/Global pair exists to chain from.

CN exclusive

An event is marked cnExclusive once both of these are true:

  • It has never had a confirmed Global date.
  • Its estimated window closed more than 30 days ago.

This usually means the event isn't coming to Global at all - the 30-day buffer just keeps a slightly delayed event from getting flagged red too early.

How often this updates

This page rebuilds once a day: a scheduled job re-fetches the wiki data, recalculates every date using the rules above, and republishes the result. Data on this page can be up to a day old.
