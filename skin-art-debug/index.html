Scans every operator skin against the image mirrors the Operator page's skin gallery reads from, and reports which ones can't find their avatar and/or full illustration on either mirror right now. This doesn't fix anything by itself -- it's here to tell you which skins are affected and why, since a missing image usually means none of the mirrors this site reads from (jsDelivr/Aceship, jsDelivr/akgcc, myrtle.moe) have picked up that file yet -- most common for very recently released skins and collab-exclusive content -- rather than a bug on this site.

Skins that only exist on the CN server (no EN release yet) are expected to be missing and are filtered out of the results below by default -- there's a toggle to see them anyway.

This runs a few thousand small network requests (existence checks only, nothing is downloaded in full) against those mirrors -- it only runs when you press the button below, never automatically.
